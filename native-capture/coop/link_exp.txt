# Plan 6 Task 4: EXP in a joined link battle. The tower's link multi (pk_coop_link.c) with the rewards' patches (pk_coop_link_rewards.c,
# scripts/coop_link_emerald.s' `task 4`): Cmd_getexp's skip of link battles lifted, each side's Pokémon given a single battle's
# full EXP by the master's wrapper, the partner's own Pokémon given theirs by its own game's controller (and mirrored in the master's
# copy so the level-up text and the stats are right). Needs EMERALD_PARTNER_SAVE (`$PARTNER_SAVE`; scripts/coop_headless_check.sh).
#
# Both leads get 999 HP so the level 50 foes' hits faint nobody; the foe at battler 1 is left with 1 HP, so the first hit of the first
# turn faints it (ZIGZAGOON Lv 50, 60 x 50 / 7 = 428 EXP, x 1.5 for a trainer's: 642). Both games hold the host's three Pokémon at
# slots 0-2 and the partner's at 3-5: 0 TORCHIC, 3 MUDKIP; slot 4 (the partner's benched WURMPLE) is counted as sent in by hand
# (gSentPokesToOpponent) to show a benched partner Pokémon's EXP go to the partner's own game as well. The host presses A through the
# level-up boxes (the master's screen draws them, the partner's too).
# The host presses exactly as many As as the level-ups need (130): the trainer sends in a replacement foe (its own low level) after the first
# faint, and any more presses start a second turn in which the host kills it and a second award (+37 for each sent-in side) lands.
#
# Checked: each side divides the yield by its own sent-in Pokémon, not by all six: the host's TORCHIC (alone on its side) gets the whole
# 642, the partner's MUDKIP and WURMPLE (two) 321 each, on the game that owns them (the partner's core) and in the host's copy of
# them (both cores agree on them); the host's Pokémon on the partner's core get nothing there, nor does a benched one that was not sent
# in; the levels follow (TORCHIC Lv 11: 794 EXP, MUDKIP Lv 9, WURMPLE Lv 7).
#
